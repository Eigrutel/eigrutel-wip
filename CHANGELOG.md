# Changelog

Toutes les modifications notables de WIP sont consignées dans ce fichier.

Le projet suit une numérotation de version de type `MAJEURE.MINEURE.CORRECTIF`.

## [1.1.0] — 11-08-2026

### Ajouté

- changement d’état directement depuis la fiche d’une page ;
- menu d’état personnalisé avec pastilles de couleur ;
- nouvelle palette de couleurs par défaut pour les états.

### Corrigé

- correction du sélecteur de couleur sur iPad / Safari : le spectre et les curseurs restent ouverts pendant le réglage ;
- mise à jour immédiate de la couleur des vignettes de pages ;
- mise à jour immédiate de la légende lors d’un changement de couleur ;
- synchronisation immédiate des pastilles du menu d’état de la fiche.

## [1.0.0] — 10-08-2026

### Première version stable

- suivi d’un projet de bande dessinée page par page ;
- titre du projet, nombre de pages et deadline ;
- états de production colorés ;
- états personnalisables ;
- ajout, suppression et réordonnancement des états ;
- restauration des états par défaut ;
- état `Terminé` protégé ;
- mode neutre et mode de modification des états ;
- tri des pages par avancement ;
- masquage des pages terminées ;
- calcul de la progression générale ;
- fiche individuelle par page ;
- date, nombre de cases et notes par page ;
- affichage du nombre de cases sur les vignettes ;
- détection des liens dans les notes ;
- calculateur de travail ;
- calcul du travail restant en pages ;
- calcul du travail restant en cases ;
- sélection des jours travaillés ;
- injection de la deadline du projet dans le calculateur ;
- sauvegarde locale automatique ;
- import / export JSON ;
- impression ;
- remise à zéro des pages ;
- remise à zéro complète ;
- mini aide intégrée ;
- interface bilingue français / anglais ;
- adaptation aux écrans mobiles ;
- favicon `favwip.png` ;
- nettoyage et commentaires bilingues du code avant publication.
